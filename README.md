# Dealbot — поиск выгодных предложений

Telegram-бот для поиска товаров с заметным снижением цены на Wildberries и Ozon.

## Как бот должен находить реальную выгоду

Одной цены «до скидки» из карточки недостаточно: она может меняться, а цена зависит от региона, авторизации и способа оплаты. Детектор будет объединять несколько независимых сигналов:

1. **Аномалия в поисковой выдаче:** цена сильно ниже других предложений той же модели и конфигурации, после исключения аксессуаров, б/у товаров и несовпадающих вариантов.
2. **Сравнение между площадками:** сопоставление бренда, модели и ключевых характеристик на WB и Ozon; сравнивать просто самые дешёвые карточки нельзя.
3. **История цены:** отмечать, стала ли цена заметно ниже ранее наблюдавшейся. Это усиливает уверенность, но не обязательно для первого сигнала.
4. **Проверка карточки:** повторно получить цену перед отправкой, чтобы не показывать временный сбой или уже исчезнувшее предложение.

В карточке бот покажет, почему товар попал в подборку: например, «на 42% ниже похожих вариантов» или «новый минимум цены за 30 дней». Если есть только рекламная зачёркнутая цена, она будет помечена как заявленная площадкой скидка, а не подтверждённая выгода.

## Как работает подписка

- после `/start` бот автоматически подписывает чат на подборку;
- сборщик проходит более 110 встроенных тем по 14 группам товаров на обеих площадках, с выдачей, отсортированной по скидке;
- бот сохраняет снимки цены и отправляет только предложения, которые проходят порог скидки и проверку повторным запросом;
- каждое предложение приходит отдельной карточкой Telegram: фото (если есть в выдаче), название, площадка, цена и кнопка перехода;
- для защиты от лавины отправляется не больше 10 карточек за один цикл и 30 за последние 24 часа на чат;
- подписка/платный доступ могут быть добавлены после проверки спроса.

## Почему пока не подключён чужой скрапер

Найденные проекты на GitHub используют внутренние интерфейсы сайтов или браузерную автоматизацию. Такие интерфейсы могут измениться, а запросы — получать CAPTCHA или блокировки. Поэтому перед подключением нужно проверить лицензию, активность репозитория и фактическую работу именно с нужными категориями. У Wildberries есть официальный API для продавцов; документация Ozon в первую очередь описывает API продавцов и сама по себе не решает поиск товаров по всей витрине.

Первая проверенная заготовка — [Marketplace-Parser](https://github.com/MaxDev43/Marketplace-Parser): MIT-лицензия, поиск по ссылкам WB/Ozon и JSON-выгрузка. Это не большой популярный проект, поэтому его нужно проверить на реальных поисковых страницах перед запуском. На GitHub есть более крупные или более специализированные проекты, но универсальный обходчик категорий архивирован, а некоторые популярные парсеры не указывают лицензию. Для низких цен нужны два слоя: сборщик товаров и наш собственный детектор аномалий.

## Ограничения автоматического поиска

Поиск не требует от пользователя вводить товары. Бот просматривает широкие темы в основных разделах. Это автоматическая выборка, но не полный перебор каждой карточки каталога: витрины содержат миллионы товаров, а внутренние страницы и API площадок могут ограничивать частые запросы. Заявленная самой площадкой скидка считается предварительным сигналом; детектор также сравнивает цену с похожими предложениями и накопленной историей.

Сборщик должен быть сменным модулем, чтобы при поломке источника заменить его, не переписывая Telegram-бота и историю цен.

## Что уже подготовлено

- `bot.py` — подписка `/start`, отключение `/stop` и фоновая автоматическая проверка; произвольные сообщения и поисковые запросы игнорируются.
- `scanner.py` — запускает парсеры WB/Ozon по встроенному списку тем и выдаёт нормализованные карточки.
- `detector.py` — ищет заметные выбросы по похожим товарам, истории и заявленной площадкой скидке.
- `db.py` — хранит подписки, историю цен, лимиты отправки и отправленные оповещения в SQLite.
- `vendor/Marketplace-Parser` — MIT-лицензированный исходник сборщика.

### Запуск локального MVP

Нужен Python 3.11 или новее. В PowerShell из папки `dealbot`:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
playwright install chromium
Copy-Item .env.example .env
```

В `.env` нужно вставить токен, полученный у `@BotFather`, затем запустить:

```powershell
python bot.py
```

В чате с ботом один раз нажать `/start`. Поисковые фразы писать не нужно; обычные сообщения бот игнорирует. Сканер проходит более 110 поисковых тем в 14 группах товаров; интервал по умолчанию — 10 минут. `/stop` отключает рассылку. По умолчанию бот отправляет не больше 10 карточек за цикл и 30 за 24 часа, распределяя находки по группам и убирая похожие товары с близкими ценами. Порог сравнения с аналогами регулируется `PEER_DISCOUNT_THRESHOLD`, а порог заявленной площадкой скидки — `LISTED_DISCOUNT_THRESHOLD`.

Это MVP: он не обходит каталог целиком, а циклически проверяет широкую встроенную выборку. Карточки отправляются с изображением товара, ценой, причиной срабатывания и кнопкой на исходный товар; если фото недоступно, бот покажет аккуратную текстовую карточку. Результаты и доступность внутренних интерфейсов маркетплейсов могут меняться.
