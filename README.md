# Dealbot 2.0 — поиск ценовых аномалий на Ozon

Telegram-бот непрерывно исследует поисковую витрину Ozon и присылает только прошедшие строгую проверку предложения. Wildberries в рабочем сканере не используется.

## Как устроен поиск

Вместо постоянного списка категорий и поисковых фраз используется адаптивное случайное блуждание:

1. При первом запуске создаются несколько общих стартовых направлений.
2. Каждый завершённый поиск порождает новые направления из названий найденных товаров: бренды, модели, поколения и сочетания значимых слов.
3. SQLite сохраняет направления, попытки и оценку их полезности между перезапусками.
4. Следующее направление выбирается случайно с весом качества. Новые направления получают шанс на исследование, а полезные постепенно выбираются чаще.
5. Два независимых потока поиска работают параллельно. Каждый поток владеет собственной Playwright-сессией Ozon; отдельный потребитель проверяет карточки.
6. Недавно найденные предложения хранятся в кэше 2 часа и сравниваются между разными поисковыми направлениями.
7. Результаты обрабатываются сразу после завершения отдельного поискового запроса; ожидать завершения общего обхода не нужно.

Это исследовательский поиск по выдаче Ozon, а не полный экспорт всего каталога. Площадка может менять выдачу, ограничивать запросы и показывать разные результаты в зависимости от региона и сессии.

## Как подтверждается выгода

- Сравниваются только товары с достаточно близкими названиями и модельными идентификаторами.
- Проверяются конфигурации, ёмкость, размер, состояние и комплектность. Несовпадающие варианты и аксессуары исключаются.
- Для сравнения нужно не менее двух сопоставимых предложений; экстремальные цены фильтруются устойчивой статистикой.
- Детектор рассчитывает оценку 0–100 с учётом величины аномалии, уверенности совпадения и числа аналогов.
- Перед отправкой бот открывает карточку Ozon повторно, сверяет название и актуальную цену. Если цена изменилась более чем на 10%, предложение отклоняется.
- Зачёркнутая цена и рекламная скидка Ozon не считаются доказательством выгоды.
- Повторное уведомление по той же карточке отправляется только после дальнейшего снижения цены на 5% или более.

Для б/у и новых товаров сравнение ведётся отдельно. Если состояние указано неоднозначно, товар не сопоставляется с явно новым или б/у.

## Telegram

- `/start` — включить уведомления.
- `/stop` — отключить уведомления.
- Каждая находка отправляется отдельным сообщением с текущей ценой, причиной отбора и ссылкой на Ozon.
- По умолчанию — не более 30 сообщений на чат за 24 часа.

## Хранение данных

SQLite хранит подписки, историю наблюдений, двухчасовой кэш предложений, отправленные уведомления и дерево поисковых направлений. Инициализация выполняется миграциями; существующая база не сбрасывается. История цен хранится 3 дня, кэш предложений — 2 часа, записи доставки и уведомлений — 30 дней. Очистка не удаляет подписки и поисковые направления.

## Настройка

Скопируйте `.env.example` в `.env` и задайте токен Telegram:

```env
BOT_TOKEN=...
RESULTS_PER_MARKETPLACE=12
SEARCH_WORKERS=2
MIN_DEAL_SCORE=78
HISTORY_DROP_THRESHOLD=0.30
MAX_ALERTS_PER_DAY=30
```

Параметры:
- `SEARCH_WORKERS` — число параллельных поисковых потоков (ограничено 1–3).
- `RESULTS_PER_MARKETPLACE` — максимум карточек в одной поисковой выдаче.
- `MIN_DEAL_SCORE` — минимальная оценка аномалии по аналогам.
- `HISTORY_DROP_THRESHOLD` — минимальное снижение относительно собственной истории цены.
- `MAX_ALERTS_PER_DAY` — дневной лимит уведомлений на чат.

## Установка и запуск

Нужен Python 3.11+ и Linux/Windows-среда с установленным Chromium для Playwright:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
cp .env.example .env
python bot.py
```

На Windows вместо активации через `source` используйте `.venv\\Scripts\\Activate.ps1`; вместо `cp` — `Copy-Item`.

## Структура

- `bot.py` — Telegram-команды, непрерывный цикл и отправка проверенных находок.
- `scanner.py` — параллельный random walk по Ozon и генерация новых направлений.
- `detector.py` — строгое сопоставление моделей и оценка ценовой аномалии.
- `db.py` — SQLite, состояние random walk и сроки хранения.
- `vendor/Marketplace-Parser` — используемый Ozon-парсер; его исходники не изменяются этим проектом.
